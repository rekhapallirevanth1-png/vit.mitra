1. Executive Summary & Overview

The Vishnu Institute of Technology — MITRA Attendance Management System is a full-stack, role-based application engineered to manage, track, verify, and correct student attendance for the MITRA Club. The system provides multi-horizon analytics across Daily, Weekly, and Monthly cycles, with immutable audit logging and discrepancy resolution.

Key Architectural Highlights:
  • Dual-Mode Deployment: Can run as a full-stack REST service (node server.js on port 3000) or as a zero-dependency, self-contained standalone offline file (dist/index.html).
  • Strict Role-Based Access Control (RBAC): Separates the Admin (24PA1A4297 / R Revanth) with full Mark, Correct, and Audit powers from Club Members who have strict 1-Person View-Only access.
  • Master Excel Dataset (vit.xlsx): Incorporates all 68 officially enrolled students across 7 academic branches (AI&DS, AI&ML, CSE, IT, ECE, CSBS, MECH) and 5 club wings.

4. Core Features & Functional Workflows

4.1. Auto Date Change & Live Digital Clock

The system evaluates new Date() upon application boot, setting the active tracking date automatically to today's live date. A real-time digital clock displays Indian Standard Time (IST). At midnight (00:00:00), an auto-rollover watcher switches the active session to the new calendar day without requiring manual reloads.

4.2. Multi-Horizon Attendance Tracking

  • Daily Tracker (Tab 1): Real-time roll call with color-coded status badges: Present (Emerald), Absent (Rose), Late (Amber), and On-Duty / OD (Sky Blue). Includes session title, session type selector, and retroactive date notice.
  • Weekly Trackage Grid (Tab 2): 7-day rolling matrix showing member rows against date columns. Includes navigation buttons (Previous Week, Next Week, This Week) and two Chart.js visual analytics: Daily Attendance Breakdown (bar chart) and Wing-wise Attendance Rate (bar chart).
  • Monthly Summary Scorecard (Tab 3): Comprehensive monthly performance table calculating Sessions Conducted, Present, OD, Late, Absent, and Attendance %. Automatically applies eligibility standing badges:
    • 🟢 Good Standing: Attendance ≥ 85%
    • 🟡 Warning: Attendance 75% – 84%
    • 🔴 Low Attendance / Ineligible: Attendance < 75%

4.3. Retroactive Date Correction & Immutable Audit Trail

Admin can select any past date using the date picker to inspect historical records. When an entry is corrected, an immutable audit record is created in db.auditLogs storing: Date, Student Name, Reg No, Old Status, New Status, Justification/Reason, Admin Name, and Timestamp.

4.4. Discrepancy Reporting & Review Queue

If a student was incorrectly marked absent, they can open 🚩 Flag Wrong Attendance, select the date, specify the correct status, and submit a reason. The request arrives in the Admin's Discrepancy Queue, where the Admin can approve and automatically correct the date record with a single click.

4.5. "+ Add Member" Feature

Accessible from the Login Gate, the App Header, and the Daily Tracker. Captures Full Name, Vishnu Reg. No., Branch, Wing, Batch, Role, and Email. Automatically populates attendance records for the new student across all session dates in db.attendance so the student immediately appears in all historical and current reports.

4.6. Flexible Password Management

Admin and Members can sign in using default password 123 or any arbitrary password. Clicking 🔑 Change Password opens a modal to set a personal password, which is immediately stored in db.passwords and verified on subsequent sign-ins.

6. REST API Reference

Method & Endpoint Payload Parameters Description
GET /api/bootstrap None Returns full application state (members, sessions, attendance, discrepancies, logs).
POST /api/auth/login { role, identifier, password } Authenticates Admin (24PA1A4297) or Club Member with password verification.
POST /api/auth/change-password { identifier, newPassword, confirmPassword } Updates personal portal password in database.
POST /api/attendance/mark { date, memberId, status, note, isCorrection, reason } Marks or retroactively corrects single member attendance.
POST /api/attendance/bulk { date, status, memberIds, sessionTitle, sessionType } Bulk marks attendance for all or filtered members on a date.
POST /api/members { name, regNo, branch, wing, role, batch, email } Inducts a new member into the roster and attendance matrix across all dates.
POST /api/discrepancies { date, memberId, requestedStatus, reason } Submits a member's wrong attendance correction request.
POST /api/discrepancies/resolve { id, action: 'approve' | 'reject', adminNote } Admin resolves discrepancy request and applies correction.
GET /api/datasets None Lists all dataset files with size, row count, and previews.
